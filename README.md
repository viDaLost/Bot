# Sunset Telegram Bot Pro

Telegram-бот для автоматической публикации премиальных изображений со временем «заход солнца минус 1 час».

## Что умеет бот

- 10 готовых премиальных стилей: Obsidian Gold, Neon Riviera, Aurora Crystal, Desert Couture, Celestial Noir, Rosé Horizon, Emerald Atelier, Azure Residence, Ivory Editorial и Monochrome Prestige.
- 5 адаптивных форматов изображения:
  - `16:9` — горизонтальная публикация;
  - `9:16` — Stories / Reels;
  - `1:1` — квадрат;
  - `4:5` — вертикальная публикация;
  - `3:2` — фотографический формат.
- Отдельная композиция для горизонтальных, квадратных и вертикальных изображений без растягивания макета.
- Управление каналами и чатами через inline-кнопки.
- Расписания: один раз, ежедневно, по дням недели или ежемесячно.
- Предпросмотр перед сохранением и тестовая отправка в канал.
- Изменение времени, стиля, формата и заголовка сохранённого расписания.
- Отдельный интерактивный редактор по команде `/editor`.
- Автоматическая очистка пользовательского ввода, служебных запросов, временных предпросмотров и созданных PNG-файлов.
- История отправок, уведомления об ошибках, экспорт и импорт `bot.db`.
- В канал или чат отправляется только изображение, без подписи.

## Структура

- `bot.py` — меню, сценарии создания и управления расписаниями.
- `image_generator.py` — адаптивный генератор изображений и визуальные стили.
- `image_editor.py` — интерактивный редактор `/editor`.
- `scheduler.py` — планировщик и отправка публикаций.
- `database.py` — SQLite и автоматические миграции.
- `run_bot.py` — Docker entrypoint и запуск polling.
- `Dockerfile` — production-сборка на Python 3.12.

## Запуск через Docker

```bash
docker build -t sunset-bot .

docker run -d \
  --name sunset-bot \
  --restart unless-stopped \
  -e BOT_TOKEN="YOUR_TELEGRAM_TOKEN" \
  -e ADMIN_IDS="1288379477" \
  -e DATABASE_PATH="/app/data/bot.db" \
  -v sunset-bot-data:/app/data \
  sunset-bot
```

Каталог `/app/generated` используется только для временных изображений. После отправки бот удаляет их автоматически. Базу рекомендуется хранить в volume `/app/data`.

## Переменные окружения

```env
BOT_TOKEN=YOUR_TELEGRAM_TOKEN
ADMIN_IDS=1288379477
DATABASE_PATH=/app/data/bot.db
```

Несколько Telegram ID указываются через запятую:

```env
ADMIN_IDS=1288379477,987654321
```

Не добавляйте `.env` и рабочую базу данных в GitHub.

## Обновление существующей установки

При старте `init_db()` автоматически добавляет колонку `image_format` со значением `16:9`. Старые значения стиля `classic` также поддерживаются и отображаются как Obsidian Gold. Удалять существующий `bot.db` не требуется.

## Важно

Бот отправляет публикацию в заданное в расписании время. На изображении показывается рассчитанное астрономическое время «закат минус один час» для выбранной локации и даты.
